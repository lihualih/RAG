# Python 基础速记

## 1. 变量与类型
Python 常见内置类型包括 `int`、`float`、`str`、`list`、`dict`、`set`、`tuple`。
变量不需要显式声明类型，解释器会在运行时推断类型。

## 2. 条件与循环
条件判断使用 `if / elif / else`。
循环常用 `for` 与 `while`，其中 `for` 常搭配 `range()` 遍历整数序列。

## 3. 函数
函数通过 `def` 定义，支持位置参数、关键字参数、默认参数。
函数可以返回任意对象，若没有 `return`，默认返回 `None`。

## 4. 异常处理
异常处理使用 `try / except / finally`。
建议捕获具体异常类型，避免直接 `except Exception` 吞掉真实错误。

## 5. 常用实践
- 使用虚拟环境隔离依赖
- 代码风格遵循 PEP 8
- 使用类型注解提升可维护性
- 为核心逻辑补充单元测试
